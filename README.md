# Portfolio Starter

This is a static portfolio starter that runs by opening `index.html` in a browser.

## Files

- `index.html`: content and page structure
- `styles.css`: visuals, layout, and responsive behavior
- `script.js`: reveal-on-scroll animation and footer year

## Customize

1. Replace the sample project titles, descriptions, and links in `index.html`.
2. Update the intro, about section, and contact details with your real information.
3. Adjust colors and spacing in `styles.css` if you want a different visual direction.

## Publish

You can deploy this on GitHub Pages, Netlify, Vercel, or any static hosting service.
